# 🚀 Overview

AI Image Detector is an intelligent web application that analyzes uploaded images using a pre-trained AI model from Hugging Face. The platform provides fast and accurate image predictions through a simple and user-friendly interface.

Built using **Python**, **Flask**, **HTML**, **CSS**, and **JavaScript**, the system integrates AI-powered image classification capabilities for real-time image analysis.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/shahreenmansuri/AI-Image-Detector.git
cd AI-Image-Detector
```

---

## 2️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Application

```bash
python app.py
```

Application runs at:

```text
http://127.0.0.1:5000
```

# 🎯 How It Works

1. Upload an image using the web interface  
2. Flask backend receives the image  
3. Hugging Face AI model processes the image  
4. AI generates prediction results  
5. Output is displayed instantly to the user
